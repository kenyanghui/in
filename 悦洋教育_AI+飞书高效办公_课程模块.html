📝 模块一：飞书云文档基础

什么是飞书云文档？

飞书云文档是飞书套件中的在线文档工具，类似Google Docs或Notion，但深度集成了飞书的IM、日历、多维表格等能力。核心特点：

🌐
在线协作
多人实时编辑 · 自动保存
💬
评论+@提及
直接分配给具体人
📋
任务管理
创建待办 · 截止日期
🔗
一键转PPT
文档内容 → 幻灯片

基础操作速览

操作方法快捷键/Tips
新建文档飞书首页 → 云文档 → "+" → 选择模板Ctrl+Shift+N
分享协作右上角"分享" → 输入成员/链接设置"可编辑/可评论/可查看"权限
@提及输入 @ + 成员名字被@的人会收到飞书消息通知
添加评论选中文字 → 右侧"评论"图标评论可@人并分配任务
插入表格菜单"插入" → "表格"支持公式和条件格式
插入多维表格"/" → "多维表格"项目管理/数据收集神器
版本历史菜单"文件" → "版本历史"可回溯任何历史版本
模板中心新建文档 → "模板"商业计划书、会议纪要等模板

🤖 云文档 + Claude AI 协作

🚀 核心工作流：Claude → 飞书文档 让Claude AI帮你完成文档的内容生成和结构设计，然后在飞书文档中进行协作打磨和最终呈现。

三种协作模式

模式Claude角色适用场景示例
① AI先写，人再改 初稿生成器 商业计划书框架、市场分析报告 让Claude生成BP初稿 → 粘贴到飞书 → 团队协作修改
② 人先写，AI润色 编辑助手 路演演讲稿、项目说明文档 在飞书写草稿 → 复制给Claude润色 → 粘贴回飞书
③ AI辅助，边写边问 实时顾问 研究过程、数据分析 写文档时遇到问题 → 问Claude → 将答案整合进文档

Prompt 模板库

📄 商业计划书大纲

"我是[年龄]岁的学生，想做一个关于[产品/服务]的项目。请帮我写一份商业计划书的大纲，包含：痛点分析、目标用户、解决方案、商业模式、市场分析、竞争分析、实施计划。每个部分用2-3句话简单描述。"

📊 市场分析报告

"请帮我分析[行业/领域]的市场情况，从以下维度展开：市场规模、主要参与者、用户需求、未来趋势。语言简单易懂，适合[年龄]岁青少年阅读。"

✍️ 文档润色

"请帮我把以下这段文字润色得更专业、更有说服力。保持原意，但让语言更精炼：[粘贴文字]"

💡 教学要点 引导学生在使用AI生成内容时，始终问自己三个问题：
1️⃣ AI说的对吗？ — 培养事实核查意识
2️⃣ 这是我的声音吗？ — 保持个人风格，不照搬AI
3️⃣ 还能更好吗？ — AI是起点，不是终点

⚡ 实操工作流：从0到1完成一份文档

1

Step 1：需求定义

明确要写什么文档、目标读者是谁、核心信息是什么。在飞书新建文档并写下标题和3个关键词。

2

Step 2：AI生成初稿

打开Claude AI，输入上述"文档大纲"prompt，将生成的结构复制到飞书文档中。

// 例：AI生成的BP大纲粘贴到飞书后的效果
📄 商业计划书：校园二手书平台
├── 1. 痛点分析（待填写）
├── 2. 目标用户（待填写）
├── 3. 解决方案（待填写）
├── 4. 商业模式（待填写）
└── 5. 财务计划（待填写）
3

Step 3：逐段填充+AI辅助

每个部分让Claude生成具体内容 → 理解后用自己的话改写 → 粘贴到飞书。关键：不要直接复制AI输出，要理解后再重写。

4

Step 4：协作打磨

将文档分享给团队成员 → 使用评论功能提修改意见 → @提及具体负责人 → 分配任务。

// 飞书评论示例
@李明 "这里的市场数据需要查一下最新报告，我来补充"
@小张 "商业模式部分画个收入模型表格？" ✅ 已分配任务
5

Step 5：最终审阅+输出

通读全文，用Claude做最终润色。确认格式统一、逻辑连贯。导出为PDF或分享链接给导师/评委。

📊 模块二：飞书幻灯片基础

🎨 核心原则：内容先行，设计后至 好的PPT来自好的内容结构，而不是炫酷的动画。先搞定"说什么"，再考虑"怎么呈现"——这正是AI最擅长帮助你的地方。

基础操作速览

操作方法Tips
新建幻灯片飞书 → 云文档 → 新建 → 幻灯片从模板库中选择路演/项目汇报模板
从文档转PPT打开飞书文档 → "..." → "转换为幻灯片"自动根据标题层级生成页面结构
主题与模板右侧"主题"面板 → 选择配色方案保持品牌色统一（悦洋品牌色：深蓝+金色）
插入图表菜单"插入" → "图表"支持柱状图、折线图、饼图等
插入视频"插入" → "视频" → 粘贴链接支持B站/YouTube嵌入
演讲者备注底部"点击添加演讲者备注"路演时的提词器
动画与过渡选中元素 → "动画"面板适度使用，不要过度

路演PPT的标准结构（6页黄金法则）

1️⃣
封面
项目名称+团队+日期
2️⃣
痛点
我们发现什么问题？
3️⃣
方案
我们的产品/服务是什么？
4️⃣
市场
谁来买单？市场规模多大？
5️⃣
优势
为什么是我们？
6️⃣
行动
我们需要什么？下一步？

🎨 幻灯片 + Claude AI 协作

AI驱动的PPT制作工作流

阶段AI做什么你做什么
① 内容策划 生成PPT大纲结构、每页核心信息 确定主题→给Claude写prompt→选择合适的结构
② 文案撰写 写标题、要点、过渡句、演讲者备注 审核内容准确性→调整语气风格→补充个人故事
③ 设计建议 推荐配色方案、页面布局、视觉层次 选择飞书主题→按建议排版→微调细节
④ 演讲稿 为每页PPT写出讲稿或演讲者备注 用自己的话说出来→根据练习调整

Prompt 模板库

🎬 PPT大纲生成

"我是一个[年龄]岁的学生，要做一个关于[项目主题]的6页路演PPT。目标受众是[评委/投资人/家长]。请帮我设计每页的标题和3个核心要点。"

🎤 演讲稿生成

"以下是我PPT每页的内容，请为每页写一段30-45秒的演讲稿，语言要自然、有感染力，适合[年龄]岁青少年在台上讲述：
[粘贴每页标题和要点]"

🎨 设计建议

"我的PPT主题是关于[项目类型]的项目路演。请给3种配色方案和字体建议，风格要[专业/活泼/创意]，适合青少年路演场景。"

⚠️ 关键提醒 AI生成的PPT内容只是草稿。你的故事、你的数据、你的真实经历才是路演的灵魂。AI帮你省去"从空白开始"的恐惧，但内容和表达必须属于你自己！

⚡ 实操工作流：从文档到路演PPT

1

Step 1：在飞书文档中写完内容

用前面学到的"Claude+云文档"工作流，先完成完整的商业计划书文档。确保标题层级清晰（H1=每页标题，H2=要点）。

2

Step 2：一键转换为PPT

在飞书文档中 → 点击右上角"..." → "转换为幻灯片"。飞书会自动根据文档标题层级生成幻灯片页面结构。

// 转换规则
文档 H1 标题 → 每张幻灯片的标题
文档 H2/H3 → 幻灯片正文要点
文档中的表格 → 自动转为PPT表格
文档中的图片 → 自动嵌入PPT
3

Step 3：AI优化每页内容

将PPT每页的要点复制到Claude，请它帮你精简文案、优化表达。飞书PPT的原生设计能力 + Claude的文案能力 = 高效产出。

4

Step 4：设计美化

选择飞书PPT的主题模板 → 调整字体大小和颜色 → 添加关键图表 → 插入项目原型截图。保持风格统一，每页不超过5个要点。

5

Step 5：准备路演

用Claude为每页生成演讲稿 → 填写到"演讲者备注"中 → 对着PPT练习3遍 → 根据练习情况修改内容。

🏗️ 综合实战：完成一份商业计划书+路演PPT

📏 评估标准

维度权重优秀（5分）合格（3分）待提升（1分）
文档质量 25% 结构清晰，内容完整，有数据支撑 结构基本完整，部分内容需补充 结构混乱，内容缺失较多
PPT设计 25% 视觉统一，信息层次清晰，图文搭配 整体整齐，有些页面可优化 风格不统一，文字堆砌
AI运用 20% 有效使用AI生成+润色，有批判性修改 使用了AI但修改较少 直接复制AI输出或未使用AI
协作沟通 15% 积极使用评论/任务，高效协作 使用了协作功能但不够充分 未使用协作功能
路演表达 15% 表达自然，自信，时间控制精准 基本流畅，偶有卡顿 生硬背诵，超时
