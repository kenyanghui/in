## 一、赛事概览

Robotics for Good Youth Challenge是**全球唯一由联合国机构直接组织的青少年机器人竞赛**，由ITU（国际电信联盟）主办，是AI for Good Impact Initiative的核心组成部分，由瑞士政府联合40+联合国姊妹机构共同举办。2025-2026赛季主题为"机器人+农业"（Robotics Applied to Agriculture），与**FAO（联合国粮农组织）**合作，支持**联合国SDG 2：零饥饿**目标。

| 项目 | 详情 |
|------|------|
| **主办方** | ITU（国际电信联盟，联合国专门机构） |
| **合作伙伴** | FAO（联合国粮农组织）、瑞士政府、40+ UN机构 |
| **年龄要求** | 10–18岁 |
| **组别** | Junior（约10–14岁） / Senior（约15–18岁） |
| **团队规模** | 1–8人（允许个人参赛，混合年龄组按最大年龄确定组别） |
| **参赛形式** | 机器人自主完成任务（全自动）+ 概念文档 + 路演 |
| **费用** | **完全免费**（所有阶段免费） |
| **平台** | 开放平台：LEGO、Arduino、Raspberry Pi、自定义均可 |
| **全球决赛地点** | 瑞士日内瓦·Palexpo（AI for Good Global Summit期间） |

## 三、主题：机器人+农业（Robotics Applied to Agriculture）

2025-2026赛季与FAO（联合国粮农组织）合作，聚焦机器人技术在农业中的应用，直接支持SDG 2：零饥饿。

### 游戏板任务

每项任务限时2分钟，**完全自主运行**（无遥控）。

#### 任务1：选择性种植与灌溉（Selective Cultivation & Irrigation）

| 要素 | 描述 |
|------|------|
| **目标** | 机器人识别彩色地块，移动到正确网格位置，"播种"种子，投放蓝色球体"浇水" |
| **核心技能** | 颜色识别、精确定位导航、物体操作 |
| **技术挑战** | 从复杂背景中分辨彩色标记、精准移动到指定坐标 |

#### 任务2：水果采摘与分拣（Fruit Harvesting & Sorting）

| 要素 | 描述 |
|------|------|
| **目标** | 机器人识别、抓取并将彩色"水果"（红、黑、绿）从高架平台分拣到对应容器 |
| **核心技能** | 物体识别与分类、机械臂/抓取机构控制、颜色分拣 |
| **技术挑战** | 从高架平台取物、多色分类、精确放置 |

### 赛事哲学

> 这不是一场速度或对战竞赛——Robotics for Good强调**工程问题解决能力**，要求选手为真实农业挑战设计机器人解决方案。

## 五、评审标准

| 评审维度 | 描述 | 悦洋对应能力 |
|---------|------|------------|
| **Innovation & Strategy（创新与策略）** | 原创性、工程巧思、任务策略设计 | ✅ AI辅助创意设计 + 机器人搭建课程 |
| **Cost-to-Impact Efficiency（成本-影响力效率）** | 以最小资源产生最大影响 | ✅ 使用回收/低成本材料的设计理念 |
| **Practical Relevance（实际相关性）** | 方案对真实农业的适用性 | ✅ SDG + 农业科技知识 |
| **Technical Performance（技术表现）** | 自主性、可靠性、任务完成度 | ✅ 编程 + 传感器 + 机械设计 |

**特别奖项：**
- 🏆 **Best Low-Cost Innovation Award**（最佳低成本创新奖）—— 鼓励使用回收材料

**不鼓励的行为：**
- ❌ 使用预组装的商业解决方案（成品机器人）
- ❌ 隐藏的自动化模块（非自主设计的模块）

> **核心发现：** 该赛事对"低成本创新"的重视在同类比赛中独一无二。使用回收材料、开源硬件、自制传感器的方案更容易获得评委青睐。这与悦洋教育提倡的"创造者精神"高度一致。

## 十、常见问题

**Q: Robotics for Good和其他机器人比赛（如FRC、WRO）有什么不同？**
A: 最大区别在于——这是**全球唯一联合国直属的青少年机器人竞赛**。强调"低成本创新"和"解决真实世界问题"，而非速度/对战。使用任何平台均可参赛，且**所有阶段完全免费**。联合国背书使其在大学申请中的含金量极高。

**Q: 澳洲学生去日内瓦参赛需要签证吗？**
A: 澳大利亚护照持有人前往瑞士短期停留（不超过90天）**不需要签证**。悦洋教育可提供出行指导和协助。

**Q: 参加比赛要买指定机器人套件吗？**
A: **完全不需要。** Robotics for Good是开放平台竞赛——你可以使用LEGO MINDSTORMS、Arduino、Raspberry Pi、Micro:bit，甚至自定义搭建的机器人。赛事鼓励使用回收和低成本材料。

**Q: 2026年3月28日澳洲决赛已经结束了，现在还来得及吗？**
A: 2025-2026赛季的澳洲决赛已结束，但2026-2027赛季将于**2026年7月10日**在日内瓦发布。现在是开始准备新赛季的最佳时机！建议报名悦洋Robotics入门包，提前6周打好基础。

**Q: 我完全零基础，可以参加吗？**
A: 完全可以。10-18岁均可参赛，Junior组就是为初学者设计的。悦洋的Robotics入门包从零开始教学，6周内带你从搭建机器人到完成农业任务。

**Q: 参赛费用真的完全免费吗？**
A: 是的。Robotics for Good Youth Challenge所有阶段——注册、参赛、全国决赛、全球总决赛——**全部免费**。不受任何参赛费用。日内瓦峰会对18岁以下参与者同样免费。
