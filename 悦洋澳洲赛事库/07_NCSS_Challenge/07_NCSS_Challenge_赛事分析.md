# NCSS Challenge (Python.Comp / Blockly.Comp) 赛事分析

> **更新日期：** 2026-05-14
> **官网：** https://groklearning.com
> **主办方：** Grok Academy (formerly Grok Learning, founded by University of Sydney)

---

## 一、赛事概览

NCSS Challenge是澳大利亚历史最悠久、规模最大的青少年编程挑战赛，由**悉尼大学**（University of Sydney）创办，现由 **Grok Academy**（前Grok Learning）运营。2024年11月，Grok Academy被 **KIK Innovation** 收购。赛事已连续举办**20年以上**，累计影响数万澳洲学生。

赛事原名NCSS Challenge（澳大利亚计算机科学学校竞赛），2025年起分为 **Python.Comp** 和 **Blockly.Comp** 两大品牌，由Grok Academy统一运营。

| 项目 | 详情 |
|------|------|
| **主办方** | Grok Academy (KIK Innovation) |
| **成立年份** | 2005年（20+年历史） |
| **适合年级** | Y5-12（按能力分阶，非严格年级） |
| **参赛形式** | 在线学习+在线编程，自动评分 |
| **费用** | **完全免费**（澳洲/新西兰学生及教师） |
| **语言** | 英文 |
| **每年赛次** | 2次（Term 1 二月 / Term 3 七月） |

---

## 二、参赛资格

面向**全体在读学校学生及教师**，不限制学校、地区或背景：

- **澳洲所有州和领地**的学生均可参加
- **新西兰**学生同样免费参加
- **教师**可免费注册并获取教学资源
- **按能力分阶**而非严格按年级划分，确保每个学生都能找到适合的起点
- **零基础友好**：Newbies（新手）和 Beginners（初级）不要求任何编程经验

---

## 三、赛程安排

每年举办**两轮**，分别在学年第一学期（Term 1）和第三学期（Term 3）：

| 轮次 | 时间 | 持续时间 | 包含级别 |
|------|------|---------|---------|
| **Term 1** | 2月中开始 | 5周 | Blockly Newbies, Blockly Beginners, Python Beginners, Python Intermediate |
| **Term 3** | 7月中下旬开始 | 5周 | 以上全部 + **Python Advanced** |

每轮周期：**5周**，每周发布新的学习笔记和问题集。建议投入时间为**每周2-3小时**。

---

## 四、五个难度级别

赛事按编程能力和学习阶段分为五个流（Stream），并非严格按年级划分：

| 级别 | 对应年级 | 工具 | 编程基础 | 说明 |
|------|---------|------|---------|------|
| **Blockly.Comp Newbies** | Y5-6 | Blockly拖拽编程 | 无需 | 图形化积木，零基础入门 |
| **Blockly.Comp Beginners** | Y7-8 | Blockly拖拽编程 | 无需 | 进阶积木编程 |
| **Python.Comp Beginners** | Y7-8 | Python | 无需/基础 | 文本编程入门 |
| **Python.Comp Intermediate** | Y9-10 | Python | 有基础 | 算法与数据结构 |
| **Python.Comp Advanced** ⭐ | Y9-10+ | Python | 较强 | 高级算法（仅Term 3开设） |

> **进阶路径建议：** Blockly Newbies → Blockly Beginners → Python Beginners → Python Intermediate → Python Advanced

## 五、学习与竞赛模式

NCSS Challenge的独特之处在于**"边学边赛"（Learn as You Go）**模式，不是单纯的竞赛：

### 学习流程
1. **每周发布学习笔记** — 讲解本周核心概念和编程知识
2. **完成问题集** — 运用所学知识解决编程题目
3. **自动评测+即时反馈** — 提交后立刻知道对错
4. **多次重交机会** — 前5次提交满分计分，之后逐步递减
5. **排行榜更新** — 全球+学校排名实时更新

### 特点
- **课程对齐**：内容对接澳大利亚Digital Technologies课程标准
- **灵活自主**：可在任意时间完成每周任务
- **即时纠错**：自动评测系统给出具体反馈，帮助学生理解错误
- **导师支持**：来自赞助企业的志愿者导师在线答疑（Atlassian、ASD、Westpac、CommBank、Macquarie、NAB、Optiver、Telstra、WiseTech Global等）

## 六、证书体系

完成至少5道题目即可获得数字证书，证书等级按澳洲评分体系划分：

| 等级 | 分数范围 | 说明 |
|------|---------|------|
| **Participation（参与）** | <50% | 完成最低要求 |
| **Merit（优秀）** | 50-64% | 达到基础水平 |
| **Credit（良好）** | 65-74% | 表现良好 |
| **Distinction（卓越）** | 75-84% | 表现优异 |
| **High Distinction（高等卓越）** | 85-99% | 表现杰出 |
| **Perfect Score（满分）** | 100% | 全部正确 |

> 证书为**数字版**，可下载保存。无实物证书或奖杯。

## 十一、常见问题

**Q: 孩子没有编程基础可以参加吗？**
A: 完全可以。Newbies和Beginners级别专为零基础设计，Blockly拖拽编程不需要任何编程经验。

**Q: 2026年参赛全部免费吗？**
A: 是的。澳洲和新西兰所有学生和教师均可免费参加，由WiseTech Global的870万澳元赞助支持。

**Q: 证书有用吗？**
A: NCSS Challenge已经举办20+年，在澳洲教育界有很高的认可度。High Distinction和Perfect Score证书是大学申请中展示编程能力的有力证明。

**Q: 和ICAS/AMC等竞赛有什么区别？**
A: NCSS Challenge是"边学边赛"模式，不要求参赛者具备现成的编程能力。它更像是一个带竞赛元素的学习课程，而非纯选拔性考试。

**Q: 悦洋辅导和学校学习冲突吗？**
A: 不冲突。悦洋辅导专为NCSS Challenge设计，与澳洲Digital Technologies课程目标一致，可同时备赛和提升校内成绩。

**Q: 最多可以参加几次？**
A: 每轮都可以参加（T1和T3），且可以逐年挑战更高难度级别。很多学生从Y5的Blockly Newbies一路学到Y10+的Python Advanced。
