## 一、赛事概览

IEO（International Economics Olympiad，国际经济学奥林匹克）是全球仅有的13个国际科学奥林匹克之一，由诺贝尔经济学奖得主 Eric Maskin 教授（哈佛大学，2007年诺贝尔经济学奖）创办，Daron Acemoglu（2024年诺贝尔经济学奖得主）联合赞助。AAEO（Australasian Economics Olympiad，澳大拉西亚经济学奥林匹克）由UNSW商学院和CIEE（Consortium for Inclusive Economics Education）主办，是亚太地区通往IEO全球决赛的核心区域站。

| 项目 | 详情 |
|------|------|
| **创办人** | Prof. Eric Maskin（诺贝尔经济学奖得主，哈佛大学） |
| **联合赞助** | Prof. Daron Acemoglu（2024年诺贝尔经济学奖得主） |
| **IEO地位** | 全球仅13个国际科学奥林匹克之一 |
| **AAEO主办方** | UNSW Business School + CIEE |
| **年龄要求** | 澳洲AEO：Y10-12（学校推荐）；IEO全球：Y7-12，20岁以下 |
| **团队规模** | IEO全球决赛4人/队 |
| **参赛形式** | 笔试+金融模拟+团队案例分析 |
| **费用** | AEO仅AUD $25/人 |
| **语言** | Senior组全英文；Junior组可中英双语 |
| **全球决赛地点** | 2026年：苏州，中国 |

### 澳洲参赛路径

```
AEO（澳大利亚经济学奥赛，校内笔试）
    → AAEO（澳大拉西亚奥赛，UNSW悉尼）
        → IEO Global Finals（全球决赛）
```

AEO Top 5 全国优胜者代表澳大利亚参加AAEO。AAEO优胜者晋级IEO全球决赛。

## 三、三大竞赛模块详解

IEO/AAEO包含三个竞赛模块，全面考察经济学理论、金融素养和实际问题解决能力。

### 模块1：Economics Concepts & Analysis 经济学概念与分析（30%）

- **形式：** 60分钟笔试，选择题+开放式问题
- **Senior组内容：**
  - **微观经济学：** 市场结构、博弈论、纳什均衡、要素市场、外部性
  - **宏观经济学：** AD-AS模型、菲利普斯曲线、财政与货币政策
  - **国际经济学：** 贸易理论、汇率、国际收支
- **Junior组内容（2026新增）：**
  - **微观经济学：** 供给与需求、弹性、市场均衡
  - **宏观经济学：** GDP、通货膨胀、失业
  - **个人理财**
- **计分规则：** 答对+4分，答错-1分，不答0分

### 模块2：Financial Literacy Assessment 金融素养评估（20%）

- **形式：** 60分钟在线模拟——个人资产配置决策
- **涵盖主题：**
  - 财务规划、银行业务、复利、信贷
  - 投资策略、风险管理、保险、防欺诈
  - **2026新增：** 加密货币、区块链、ESG投资
- **Senior组要求：** Python/Stata/R 数据分析能力

### 模块3：Business/Policy Case Study 商业/政策案例研究（50%）

- **形式：** 团队合作——24小时准备 → 英文陈述 + Q&A答辩
- **2026评分标准：**

| 维度 | 权重 |
|------|------|
| 模型假设合理性 | 30% |
| 财务预测准确性 | 25% |
| ESG价值创造（2026新增） | 20% |
| 创新性与可行性 | 15% |
| 团队展示与Q&A | 10% |

> **核心发现：** 模块3权重最高（50%），且悦洋的AI商科教学（商业模型构建、数据分析、路演答辩）与此高度匹配。

## 七、IEO vs DECA vs FBLA 对比

| 维度 | IEO | FBLA | DECA |
|------|-----|------|------|
| **类型** | 学术奥林匹克（经济学科学） | 商业概念竞赛 | 应用商业竞赛 |
| **难度** | 最高（需深入经济学理论） | 入门友好 | 中等 |
| **核心能力** | 经济理论+数据分析+案例 | 商业知识+选择题 | 角色扮演+商业展示 |
| **认可度** | 诺奖背书，13大科学奥赛之一 | 广泛但层级较低 | 广泛，偏职业导向 |
| **形式** | 笔试+金融模拟+案例答辩 | 选择题+展示 | 角色扮演+商业报告 |
| **适合人群** | 志在经济/金融学术路线的学生 | 商业入门兴趣 | 实践型学生 |

> **悦洋建议：** IEO适合学术能力强、有志于经济学/金融方向的学员。对于偏实践或入门学员，可先参加FBLA/DECA过渡。

## 十、常见问题

**Q: 澳洲学生如何参加IEO？**
A: 澳洲学生通过AEO（澳大利亚经济学奥赛）选拔路径参赛。AEO Round 1为校内笔试，Top 5全国优胜者代表澳大利亚参加AAEO（UNSW悉尼站）。AAEO优胜者晋级IEO全球决赛。

**Q: AEO报名需要什么条件？**
A: 必须通过学校经济学老师报名，学生不能个人注册。费用为AUD $25/人。

**Q: IEO和DECA/FBLA可以同时参加吗？**
A: 完全可以。IEO侧重经济学学术深度，DECA/FBLA侧重商业实践。三个赛事侧重点不同，可以同时准备。悦洋建议学术能力强的学员以IEO为主，附加DECA/FBLA作为补充实践经历。

**Q: 我不擅长数据分析，能参加IEO吗？**
A: 可以。团队推荐配置中，数据分析可以由专门的数据处理员负责。你可以担任理论分析师或陈述负责人。悦洋IEO全程孵化项目也包括Python/Stata入门教学。

**Q: IEO对大学申请有多大帮助？**
A: 非常大。IEO是13个国际科学奥林匹克之一，其学术认可度远高于普通商赛。超过60%的全球决赛选手进入世界Top 50大学。在英美澳本科申请中，IEO经历是极强的学术证明。

**Q: AAEO需要去悉尼线下参加吗？**
A: 是的。AAEO在UNSW悉尼线下举行，包括讲座、案例研究和实地参访（RBA、NSW Treasury）。悦洋提供参赛行程指导。

**Q: 2026年AEO什么时间开始？**
A: 2026年AEO日期尚未公布，预计5月下旬公布。参考2025年日程，Round 1在5月24日。建议提前准备，密切关注 aeo.org.au。
