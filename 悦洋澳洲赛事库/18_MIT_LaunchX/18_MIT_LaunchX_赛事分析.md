## 一、赛事/项目概览

MIT LaunchX 发源于麻省理工学院，是全球最具影响力的**青年创业实战项目**之一。与Conrad Challenge偏重"STEM+商业方案"、Diamond Challenge偏重"商业计划书比赛"不同，LaunchX的核心定位是**"做一家真公司"**——学员不是写一份BP参加比赛，而是在6-8周内从0到1创建一家真实的、有收入的创业公司。

| 项目 | 详情 |
|------|------|
| **主办方** | LaunchX Organisation（MIT校友创立，现独立运营） |
| **创办年份** | 2012年（MIT校园内启动） |
| **年龄要求** | 14-18岁（Grades 9-12）；在线项目接受18-22岁 |
| **录取率** | 旗舰项目约**30%** |
| **项目形式** | 线上/线下实战营（非传统竞赛） |
| **费用** | **USD $1,995 - $11,495**（付费项目，非免费竞赛） |
| **语言** | 全英文 |
| **项目地点** | 在线 / 美国圣地亚哥 / 其他LocationX城市 |
| **核心理念** | Build a real startup. Not a plan — a business. |

> ⚠️ **重要说明：** MIT LaunchX 是一项**付费创业教育项目**（paid entrepreneurship program），而非传统意义上的免费竞赛。它适合追求**高质量创业实战体验**、希望在大学申请中展示真实创业经历的学生。悦洋定位为"Premium Entrepreneurial Experience"。

|------|------|


## 六、评审标准

LaunchX采用**综合评审（Holistic Review）**，不是简单的打分竞赛：

| 维度 | 权重 | 描述 |
|------|------|------|
| **Creativity & Innovation** | 高 | 创业想法是否新颖、有差异化 |
| **Feasibility** | 高 | 想法在6-8周内能否落地为MVP |
| **Business Acumen** | 中高 | 对商业基本逻辑的理解 |
| **Market Research** | 中高 | 是否了解目标市场、客户需求 |
| **Teamwork & Leadership** | 中 | 团队协作能力、领导潜力 |
| **Passion & Grit** | 高 | 创业热情和抗挫能力 |
| **Prototype Progress** | 中 | 项目期间的MVP开发进度 |
| **Customer Validation** | 高 | 是否获得真实客户反馈/预购 |
| **Revenue / Traction** | 高 | **$250+ pre-sales benchmark** |
| **Final Pitch** | 中 | 结业路演的质量 |

> ⚡ **关键区别：** LaunchX评审的不是"你提交的材料"，而是**你在项目期间的真实表现**。录取时看重潜力，结业时看重成果。

## 十一、常见问题

**Q: MIT LaunchX是免费的吗？**
A: 不是。LaunchX是一项付费创业教育项目，费用从USD $1,995到$11,495不等。它提供的是高质量的创业实战教育体验，而非传统的免费竞赛。

**Q: 澳洲学生可以参加吗？**
A: 可以。LaunchX欢迎国际学生，在线项目特别适合澳洲学生，无需赴美即可参加。

**Q: 需要什么背景才能申请？**
A: 不需要编程或商科背景。LaunchX看重的是创业思维、学习能力和行动力。悦洋的申请辅导可以帮助零基础学生准备。

**Q: 录取率多少？难不难？**
A: 旗舰项目约30%录取率。难度适中——不是"选最优秀的人"，而是"选最合适的人"。真诚、有创业热情、愿意付诸行动的学生录取机会很大。

**Q: 和悦洋爱创营是什么关系？**
A: 爱创营是创业启蒙和BP入门，LaunchX是进阶实战。推荐路径：爱创营 → 申请辅导 → LaunchX项目 → 大学申请材料。爱创营毕业生申请LaunchX有天然优势。

**Q: 项目结束后还能获得支持吗？**
A: 可以。悦洋的全程支持包含项目后的大学申请材料转化服务。同时，LaunchX校友网络也提供持续支持。

**Q: 如果项目期间遇到困难（语言、文化、技术）怎么办？**
A: LaunchX本身提供导师支持。选择悦洋全程支持的学生，每周有中文复盘辅导，帮助克服语言和文化障碍。
