## 一、赛事概览

悉尼大学工程学院（USYD Faculty of Engineering）面向全澳中学生提供多项工程类拓展项目。原"FEIT Hackathon"已不再作为年度赛事举办，当前核心项目包括 **Biotech Futures Challenge**（生物科技未来挑战赛）、**High School Outreach Program**（中学拓展项目）和 **NCSS Summer School**（国家计算机科学夏令营）。

| 项目 | 详情 |
|------|------|
| **主办方** | University of Sydney Faculty of Engineering |
| **核心赛事** | Biotech Futures Challenge（生物科技未来挑战赛） |
| **参赛形式** | 团队开发+导师指导+线下研讨会 |
| **费用** | 免费（Biotech Futures / Outreach） |
| **语言** | 英文 |
| **面向群体** | 全澳中学生（Y9-12） |

## 二、Biotech Futures Challenge

Biotech Futures Challenge 是悉尼大学主办的年度生物科技挑战赛，2025年吸引超过150支团队参与。

### 2.1 挑战形式
- 学生组队开发生物科技解决方案
- 由悉尼大学导师提供专业指导
- 决赛以研讨会（Symposium）形式在悉大 MacLaurin Hall 举行
- 包含科学展（Science Fair）+ 1分钟路演（Pitch）

### 2.2 2025年时间线

| 事件 | 日期 |
|------|------|
| 报名截止 | 2025.07.28 |
| 挑战周期 | 2025.08.04 - 09.19 |
| 决赛研讨会 | 2025.10.24 |

> **2026年日期待公布**，预计年中启动。

### 2.3 评审标准
- **项目质量** — 科学方法、实验设计、数据分析
- **创新性** — 解决方案的原创性和创造性
- **实际应用性** — 解决现实生物科技问题的潜力

### 2.4 评审团
- 行业专家 + 悉尼大学学者
- 提供专业反馈和职业发展建议

## 三、High School Outreach Program

悉尼大学工程学院面向中学提供的免费拓展活动：

- **校内活动（Incursions）** — 悉尼大学团队走进中学开展STEM工作坊
- **校外参观（Excursions）** — 学生到访悉大工程实验室
- **覆盖领域：**
  - 工程（Engineering）
  - 计算机科学（Computer Science）
  - 网络安全（Cybersecurity）
  - 清洁能源（Clean Energy）
  - 生物医学（Biomedical）

> **官网：** https://sydney.edu.au/engineering/industry-community/high-school-outreach.html

---

## 四、NCSS Summer School

国家计算机科学夏令营（National Computer Science School）：

- **时间：** 每年1月（暑假期间）
- **地点：** 悉尼大学
- **面向：** 澳大利亚和新西兰中学生
- **内容方向：**
  - Python 编程
  - Web 开发
  - Arduino / C 编程
- **特点：** 住宿制夏令营，沉浸式计算机科学体验

### 核心价值
- 悉大工程学院官方项目，澳洲G8申请高含金量背书

- 导师制体验，提前适应大学科研模式
- 悦洋学员可将学校科学展项目延伸参赛

## 七、常见问题

**Q: Biotech Futures Challenge 收费吗？**
A: 完全免费。注册、参赛、决赛研讨会均不收取任何费用。

**Q: 需要生物科技基础吗？**
A: 不需要。赛事注重创新思维和学习能力，悉尼大学导师会提供指导。

**Q: 2026年赛事日期何时公布？**
A: 预计2026年年中公布。建议提前关注官网 biotechfutures.org 或联系悦洋教育获取最新信息。

**Q: 海外学生可以参加吗？**
A: Biotech Futures Challenge 面向全澳中学生。海外学生可关注悦洋教育的其他国际赛事项目。

**Q: High School Outreach 如何预约？**
A: 直接通过悉大官网预约，或联系悦洋教育协助对接。
