# Others — 澳洲其他赛事参考

> **更新日期：** 2026-05-14
> **说明：** 本页汇总澳大利亚境内其他值得关注的青少年竞赛，涵盖科学、工程、商业、金融、创业、编程等领域。这些赛事暂未设立独立目录。

---

## 一、Breakthrough Junior Challenge

全球科学视频创作竞赛，由Breakthrough Prize基金会主办。

| 项目 | 详情 |
|------|------|
| **年龄** | 13-18岁 |
| **形式** | 3分钟科学视频（线上提交） |
| **费用** | 免费 |
| **奖金** | $250,000 奖学金 + $50,000 科学实验室 + $100,000 教师奖金 |
| **主题** | 物理、生命科学、数学等 |
| **网站** | breakthroughjuniorchallenge.org |
| **悦洋推荐** | ⭐ **强烈推荐** — 视频创作形式独特，含金量极高，悦洋可提供科学叙事+视频制作指导 |

> 由Mark Zuckerberg、Priscilla Chan、Yuri Milner等联合创立。全球开放，每年一届。2026届报名通常在4-6月开放。

---

## 二、BHP Foundation Science & Engineering Awards

澳洲国家级科学与工程竞赛，由BHP基金会与Australian Science Teachers Association（ASTA）联合主办。

| 项目 | 详情 |
|------|------|
| **年龄** | 9-12年级 |
| **形式** | 线下研究项目（学校/区域选拔 → 全国决赛） |
| **费用** | 免费 |
| **奖金** | 各类别$500-$5,000不等 |
| **主题** | 科学、技术、工程、数学 |
| **网站** | asta.edu.au/awards |
| **悦洋支持** | ✅ 提供研究选题与实验设计辅导 |

> 澳洲历史最悠久的中学生科学竞赛之一，政府背书，含金量高。优秀项目可代表澳洲参加国际赛事。

---

## 三、Australian Space Design Competition（ASDC）

由澳洲航天工程领域专业人士主办，模拟航天器/空间站设计。

| 项目 | 详情 |
|------|------|
| **年龄** | Y7-12（分Junior/Senior组） |
| **形式** | 团队设计挑战 + 路演展示 |
| **费用** | $40-$60/人 |
| **奖金** | 奖杯+证书+导师机会，冠军赴美参加国际决赛 |
| **主题** | 航天工程、空间站设计、月球基地 |
| **网站** | spacedesigncompetition.com.au |
| **悦洋支持** | 可选 — 适合STEM工程方向学员 |

## 四、ASX Schools Sharemarket Game

由ASX（澳洲证券交易所）主办的模拟股票投资竞赛。

| 项目 | 详情 |
|------|------|
| **年龄** | Y7-12 |
| **形式** | 线上模拟交易（$50,000虚拟资金） |
| **费用** | 免费 |
| **时长** | 10周（每学期举办） |
| **奖金** | $500-$5,000 礼品卡/奖金 |
| **主题** | 金融素养、投资策略 |
| **网站** | asx.com.au/education |
| **悦洋支持** | 可选 — 适合商科/金融方向学员 |

## 五、Bond University Entrepreneurship Competition

由Bond University（黄金海岸）主办的青年创业竞赛。

| 项目 | 详情 |
|------|------|
| **年龄** | Y10-12 |
| **形式** | 商业计划书 + 路演展示 |
| **费用** | 免费 |
| **奖金** | $1,000-$10,000 奖学金 |
| **主题** | 创业创新、商业模式设计 |
| **网站** | bond.edu.au/entrepreneurship |
| **悦洋支持** | ✅ 推荐 — 悦洋商赛产品线可直接覆盖 |

> 与悦洋的DECA/FBLA辅导体系高度重合，学员的JA Company项目也可直接转化参赛。

## 六、各类大学特定Hackathons

澳洲各大高校定期举办面向中学生的黑客马拉松/编程竞赛：

| 赛事 | 主办方 | 适合年龄 | 费用 | 备注 |
|------|--------|---------|------|------|
| **UNSW Hackathon** | UNSW CSE | Y10-12 | 免费 | 编程+创意，含工作坊 |
| **Melbourne Uni Code Jam** | UniMelb | Y9-12 | 免费 | 团队编程竞赛 |
| **QUT Hackathon** | QUT | Y10-12 | 免费 | STEM创新挑战 |
| **Sydney Uni SparkFest** | USyd | Y7-12 | 免费 | 创作与科技嘉年华 |
| **ANU Computing Challenge** | ANU | Y9-12 | 免费 | 算法与计算思维 |
| **RMIT Code Like a Girl** | RMIT | Y7-12女生 | 免费 | 鼓励女性编程 |

> 这些赛事通常每年举办，时间不固定。建议关注各大学官网获取最新报名信息。
