## 一、赛事概览

Conrad Challenge（康莱德创新挑战赛）是全球最具影响力的青少年STEM+商业创新竞赛之一，由Conrad Foundation（康莱德基金会）创办，以"传奇企业家+宇航员"Pete Conrad命名。竞赛要求学生团队发现真实世界问题，提出创新解决方案，并撰写完整的商业计划书。

| 项目 | 详情 |
|------|------|
| **主办方** | Conrad Foundation（美国） |
| **合作伙伴** | NASA、Space Center Houston、Equinor等 |
| **年龄要求** | 13–18岁 |
| **组别** | Junior（7–9年级） / Senior（10–12年级） |
| **团队规模** | 2–5名学生 + 1名成人教练（18岁以上） |
| **参赛形式** | 线上提交创新方案+商业计划+原型 → 全球决赛线下答辩 |
| **费用** | 创新阶段 $499/队（早期免费参与） |
| **语言** | 全英文 |
| **全球决赛地点** | 美国休斯顿·Space Center Houston |

## 七、澳洲学生参赛指南

### 参赛路径

```
注册(conradchallenge.org) → 组队2-5人 → 选择赛道 → 
激活阶段(免费) → 创新阶段($499/队) → 
如晋级 → 赴美参加全球决赛(Space Center Houston)
```

### 时间成本
| 阶段 | 预估时长 | 每周投入 |
|------|---------|---------|
| 选题+调研 | 2-3周 | 3-5小时 |
| 方案设计+原型开发 | 4-6周 | 5-8小时 |
| 商业计划书撰写 | 2-3周 | 3-5小时 |
| 路演准备 | 1-2周 | 3-5小时 |
| **总计** | **10-14周** | |

### 参赛建议
- **语言要求：** 全英文提交和答辩，建议雅思5.5+/托福70+水平
- **团队组建：** 建议混合技术+商业背景的队员（悦洋学员可组队参赛）
- **教练要求：** 需1名18岁以上成人教练（悦洋导师可担任）

## 九、常见问题

**Q: Conrad Challenge和Diamond Challenge有什么区别？**
A: Conrad偏重"STEM创新+商业计划"（需要技术原型），Diamond偏重"纯创业BP"（更侧重于商业模式和市场规模）。悦洋AI商科学员两个赛事可以同时参加——一份BP产出，稍加调整即可对应两套评审标准。

**Q: 澳洲学生需要签证去美国参赛吗？**
A: 是的。晋级全球决赛的团队需持有效护照和美国签证（ESTA或B1/B2）前往休斯顿。悦洋提供签证指导服务。

**Q: $499/队的费用是否包含旅行费用？**
A: 不包含。$499仅为创新阶段的参赛费。全球决赛的旅行、住宿费用需团队自行承担。

**Q: 如果我已有学校团队，还能参加悦洋辅导吗？**
A: 可以。悦洋提供"纯辅导"模式——你的团队已有成员，悦洋导师提供项目指导而不参与团队组成。
