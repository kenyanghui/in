# Science & Engineering Challenge 科学工程挑战赛 · 赛事分析

> **更新日期：** 2026-05-14
> **官网：** https://newcastle.edu.au/challenge
> **主办：** University of Newcastle（纽卡斯尔大学），联合Rotary Clubs、Deakin、JCU、QUT全国推广

---

## 一、赛事概览

Science & Engineering Challenge（SEC）由澳大利亚纽卡斯尔大学创办，是**全澳规模最大的动手STEM竞赛**。与传统的笔试/答辩型赛事不同，SEC强调"做中学"——学生团队在一天之内轮转完成多项真实工程挑战，从抗震塔到悬浮滑板，从仿生手到电网调度，每一分钟都是真正的工程师体验。

| 项目 | 详情 |
|------|------|
| **主办方** | University of Newcastle（联合Rotary Clubs、Deakin、JCU、QUT） |
| **参赛年龄** | 核心挑战日：Y9–10；另设Discovery Days（Y5–6）和Build ME a Future Days（Y7–8） |
| **团队规模** | 每校16–32名学生 |
| **参赛形式** | 一日动手竞赛，轮转多项STEM工程挑战 |
| **晋级路径** | 校内挑战日 → 州决赛 → 全国总决赛（8支州冠军） |
| **费用** | $0–440澳元（视承办方而定，Rotary赞助/JCU承办常为免费） |
| **语言** | 英语 |
| **全国总决赛地点** | 各州轮办（全国8支冠军校争夺总冠军） |

## 二、参赛资格

| 项目 | 年级 | 说明 |
|------|------|------|

---

## 三、比赛形式

SEC采用**一日挑战赛**形式，每所学校团队在一天内轮转完成多项STEM活动。每项活动持续约45–60分钟，团队按活动成绩累积得分。

**典型挑战日流程：**

```
09:00 – 09:30  开幕式 + 规则说明
09:30 – 10:30  第一轮活动（如：抗震塔建造）
10:30 – 10:45  茶歇
10:45 – 11:45  第二轮活动（如：桥梁承重测试）
11:45 – 12:30  第三轮活动（如：电网搭建）
12:30 – 13:00  午餐
13:00 – 14:00  第四轮活动（如：弹射器精准投射）
14:00 – 15:00  第五轮活动（如：仿生手抓取挑战）
15:00 – 15:30  评分 + 颁奖
```

## 四、竞赛项目描述

每场挑战日的活动项目从以下库中选取（各赛事活动组合不同）：

| 项目 | 英文名称 | 描述 | 工程领域 |
|------|---------|------|---------|
| **抗震塔** | Earthquake Tower | 用有限材料建造能承受震动台模拟地震的塔结构 | 土木/结构工程 |
| **桥梁承重** | Bridge Building | 用木棒/胶水等材料建造承重比最高的桥梁 | 结构工程 |
| **悬浮滑板** | Hovercraft | 设计和建造气垫悬浮滑板，测试悬浮高度+移动性能 | 机械/航空工程 |
| **仿生手** | Bionic Hand | 制作可抓取物体的机械手，比拼灵巧度和抓取力 | 生物医学/机械工程 |
| **弹射器** | Catapult | 建造精准弹射器，测试投射距离与命中精度 | 物理/机械工程 |
| **电网调度** | Electrical Grid | 搭建模拟电网，在预算内实现最高效、最稳定的电力分配 | 电气/能源工程 |
| **原住民鱼栅** | Indigenous Fish Traps | 结合原住民传统知识与流体力学，设计高效捕鱼装置 | 原住民科学/环境工程 |

> 每场挑战日通常会安排5–6个项目，覆盖土木、机械、电气、生物医学、环境等多元工程领域。

## 五、晋级路径

```
参加学校 → 挑战日得分排名 → 州决赛 → 全国总决赛
                                          ↑
                                   每州仅1支冠军校
```

| 阶段 | 说明 |
|------|------|
| **挑战日 (Challenge Day)** | 学校组队参与一日挑战，按总分排名 |
| **州决赛 (State Final)** | 各州高分学校晋级州决赛，争夺州冠军 |
| **全国总决赛 (National Final)** | 8支州冠军校齐聚，争夺全国总冠军 |

> 每年全国总冠军由8个州的冠军代表学校争夺。过去25年间，无数学生从挑战日开始，最终站上全国总决赛领奖台。

## 八、评审与评分

| 维度 | 说明 |
|------|------|
| **评分方式** | 每项活动按性能指标评分（如：承重比、精准度、悬浮高度、抓取力等） |
| **总分累加** | 各校所有活动得分累加，总分最高者获胜 |
| **公平调整** | 考虑到不同Challenge Day的活动组合可能不同，成绩排名按当日参赛学校排序 |
| **客观量化** | 所有评分基于可测量的性能指标（克重、厘米、秒等），最大限度减少主观评分 |

## 十一、悦洋教育参赛方案

### 🎯 方案定位

SEC是全澳学生参与面最广的STEM赛事，适合悦洋学员作为**低门槛高参与的STEM实践体验**。与编程/AI类赛事互补，SEC注重动手能力、工程思维和团队协作，是澳洲中小学STEM教育的标杆项目。

### 📋 辅导产品包

| 产品 | 适合学员 | 时长 | 价格 (AUD) | 内容 |
|------|---------|------|-----------|------|
| **🔧 团队备赛包** | 已有校内队伍的Y9–10学生 | 6周 | $680 | 校内团队训练+模拟挑战赛+活动指导手册+材料包 |
| **🏫 学校合作计划** | 希望整校参与SEC的学校 | 一学期 | $2,800 | 教师培训+设备材料包+课程整合方案+校内挑战赛组织 |

### 👨‍🏫 辅导团队

| 角色 | 职责 |
|------|------|
| **工程导师** | 各活动项目的技术指导+工程思维训练 |
| **团队教练** | 团队分工+时间管理+策略制定 |
| **材料支持** | 提供模拟赛所需材料包+工具清单 |

### 📐 辅导流程（团队备赛包）

```
Week 1-2: 赛事熟悉与团队组建
  → SEC赛事规则详解
  → 团队角色分配（土木/机械/电气/后勤）

  → 抗震塔+桥梁承重专项训练

  → 仿生手+电网调度模拟练习

Week 5: 综合模拟赛
  → 全流程模拟挑战日（5个项目轮转）
  → 时间管理+压力测试
  → 薄弱环节针对性提升
```

## 十二、常见问题

**Q: 国际学生/非澳洲居民可以参加吗？**
A: SEC面向在澳洲就读的学生，由学校统一组织报名。国际学生只要在澳洲学校就读即可参加。

**Q: 女生参加有优势吗？**
A: SEC女生参与率约50%，赛事设计鼓励多元参与。多项活动（如仿生手、鱼栅设计）不依赖体力，工程思维和创造力才是关键。

**Q: 和其他STEM赛事比，SEC有什么不同？**
A: SEC是纯粹的动手实践赛，不需要编程/论文/路演。强调一日高强度实操，对动手能力、快速学习和团队协作要求极高。与其他竞赛互补。

**Q: 不会编程可以参加吗？**
A: 完全没问题。SEC没有任何编程要求，所有项目都是物理建造+工程测试。

**Q: 2025年尤里卡奖是怎么回事？**
A: SEC在2025年获得了Australian Museum颁发的Eureka Prize for STEM Inclusion，表彰其在促进STEM包容性方面的杰出贡献——50%女生参与、55%乡村偏远地区学生、5-6%原住民学生。

**Q: 悦洋的备赛包包含材料吗？**
A: 包含。团队备赛包提供模拟挑战赛所需的核心材料包（模拟耗材+工具指导），但实际竞赛日的材料由主办方提供。
