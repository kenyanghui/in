## 一、赛事概览

AUSSEF（Australian Science and Engineering Fair，澳洲科学与工程大赛）是澳大利亚最高级别的中学生科学竞赛，也是**ISEF（International Science and Engineering Fair，国际科学与工程大奖赛）的官方选拔通道**。ISEF由美国Society for Science主办，是全球规模最大、含金量最高的青少年科学竞赛，覆盖70+国家，每年约1,800名决赛选手同台竞技。

**AUSSEF→ISEF的核心价值：** 这是澳洲中学生通往世界顶级科学竞赛的唯一官方通道。Top 9获奖项目将获得**全额资助赴美参赛**，与全球顶尖中学生在同一舞台竞争。

| 项目 | 详情 |
|------|------|
| **AUSSEF主办** | 澳洲科学工程大赛组委会 |
| **ISEF主办** | Society for Science（美国） |
| **ISEF覆盖** | 70+国家，1,800+决赛选手 |
| **年级要求** | Y9–12（澳洲学生），未满20周岁 |
| **参赛形式** | AUSSEF现场评审 → ISEF现场评审 |
| **参赛费用** | AUSSEF **免费**参赛 |
| **ISEF旅行** | Top 9项目**全免赴美参赛** |
| **语言** | 全英文 |
| **AUSSEF地点** | 澳洲大学校园（每年不同） |
| **ISEF地点** | 美国各城市巡回（洛杉矶/达拉斯/亚特兰大等） |

## 四、澳洲国家队选拔

AUSSEF是**澳洲晋级ISEF的唯一通道**。选拔机制如下：

```
AUSSEF参赛 → 现场评审 → Top 9项目入选国家队 → 
全额资助赴美参加ISEF → 代表澳洲争夺全球荣誉
```

| 选拔阶段 | 说明 |
|---------|------|
| AUSSEF作品提交 | 学生提交原创科研项目 |
| AUSSEF现场评审 | 评委在展板前面试，评估项目质量 |
| Top 9选拔 | AUSSEF评选出前9个项目，授予"澳洲国家队"资格 |
| ISEF全额资助 | Top 9学生获：往返机票+住宿+注册费+津贴，全部免费 |
| ISEF参赛 | 代表澳洲在ISEF与美国及其他国家选手竞争 |

> **关键信息：** AUSSEF完全免费，且Top 9项目获得全额资助赴美参赛。这意味着学生从参赛到ISEF决赛全程**零费用**——这是澳洲学生独一无二的福利。

## 六、评审标准

### 6.1 核心评审维度

ISEF评审标准聚焦五大维度：

| 评审维度 | 权重 | 描述 | 评分要点 |
|---------|------|------|---------|
| **Research Question** | 高 | 研究问题的清晰度和科学意义 | 问题是否明确、是否有创新价值 |
| **Methodology** | 高 | 方法的严谨性和可重复性 | 实验设计是否合理、数据是否充分 |
| **Data Analysis** | 高 | 数据分析方法和统计运用的适当性 | 是否使用正确的统计方法、结论有据 |
| **Conclusion** | 中 | 结论是否被数据充分支持 | 结果分析与讨论的深度 |
| **Presentation** | 中 | 表达清晰度和展板设计 | 口头表达+展板+视觉呈现 |
| **Creativity** | 高 | 研究思路和方法的新颖性 | 原创性、突破性思维 |

### 6.2 三阶段评审流程

| 阶段 | 评审内容 | 参与评委 |
|------|---------|---------|
| **Category Judging** | 在各自类别内评估 | 类别专家评委 |
| **Grand Award Judging** | Top项目跨类别竞争 | 高级别评审团 |
| **Special Awards** | 赞助机构专项评选 | Intel/Google/MIT等代表 |

## 七、AI项目参赛指南

### 7.1 AI/计算类项目最匹配类别

| ISEF类别 | 适合的AI项目类型 | 推荐指数 |
|---------|-----------------|---------|
| **Computational Biology & Bioinformatics** | AI/ML用于生物数据分析、蛋白质结构预测、基因组学 | ⭐⭐⭐⭐⭐ |
| **Robotics & Intelligent Machines** | AI控制机器人、自主导航、计算机视觉 | ⭐⭐⭐⭐⭐ |
| **Systems Software** | 新算法、软件框架、AI工具开发 | ⭐⭐⭐⭐⭐ |
| **Embedded Systems** | 边缘设备AI部署、IoT+ML | ⭐⭐⭐⭐ |
| **Technology: Transfers & Impacts** | AI社会影响、技术转移、SDG应用 | ⭐⭐⭐⭐ |

### 7.2 AI项目评审要点

评委对AI项目的特殊关注点：

- **问题定义**：AI解决的是什么科学/工程问题？为什么需要AI？
- **数据集**：数据来源、规模、标注质量、代表性（是否包含bias）
- **方法论**：模型选择依据、训练/验证/测试分法、超参数调优
- **评估验证**：准确率、F1-score等量化指标，交叉验证
- **伦理性**：数据隐私、算法公平性、潜在社会影响
- **实际应用**：模型是否部署？有无实际使用效果？

### 7.3 伦理要求

| 项目类型 | 要求 |
|---------|------|
| **人类参与者** | 知情同意书、IRB审批（如适用） |
| **脊椎动物** | 严格伦理指南，替代方案考量 |
| **重组DNA/人体组织** | 特定法规合规 |
| **AI/人类数据项目** | 隐私保护、知情同意、算法公平性 |
| **有害物质** | 安全规范、预先审批 |

> **AI项目特别提示：** 使用人类数据的AI项目必须在前置审批中说明数据来源、隐私保护措施和去标识化处理方式。伦理审查不通过将直接取消参赛资格。

## 十、常见问题

**Q: AUSSEF参赛完全免费吗？**
A: 是的。AUSSEF不收取任何参赛费用。而且Top 9入选澳洲国家队的学生将获得全额资助赴美参加ISEF（含机票、住宿、注册费、津贴），全程零费用。

**Q: 澳洲学生需要什么签证才能去美国参加ISEF？**
A: 需持澳洲护照（ESTA免签）或有效美国签证。悦洋提供签证指导和行程协助。

**Q: 我可以在学校做项目，然后再找悦洋辅导吗？**
A: 完全可以。悦洋的"1对1专家指导"专为已有项目的学生设计——我们帮你做论文精修、展示优化和答辩训练。

**Q: AI项目在ISEF哪个类别参赛最有利？**
A: 根据近年澳洲获奖趋势，`Computational Biology & Bioinformatics` 和 `Robotics & Intelligent Machines` 是澳洲学生表现最好的AI方向。评分时请确保项目有清晰的问题定义、完整的数据集和规范的ML评估流程。

**Q: AUSSEF和ISEF的时间怎么衔接？**
A: AUSSEF每年5月底/6月初举行，入选的Top 9国家队将在接下来的一年中深化项目，次年5月中旬参加ISEF。中间有近12个月的备赛期。

**Q: Y9学生参加AUSSEF会不会太早？**
A: 不早。AUSSEF面向Y9-12，Y9正是科研入门的好时机。悦洋的"AUSSEF科研入门"专门为Y9-10设计，从科研方法论教起，循序渐进。
